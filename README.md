
So for half life week three I'm building the tutorial project which is a MIDI Keyboard. I plan on giving it to my friend afterwards as a gift. For my keyboard I'm making a pcb and a 3d printable case. I'm useing the esp32s2 with a SN74AHCT125N and ads1115 for more IO pins. I added 5 touch keys which are piano keys, I did one encoder and two sliders with five swtiches and an LED for each switch.
